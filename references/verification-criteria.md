# 验证判据库

每一条都是**用一次错误换来的**。判据的价值在于：它能把"看起来很完整但站不住"的结论筛掉。

---

## 一、归因判据：判断内容是谁发的

| 类型 | 判据 | 怎么验证 |
|---|---|---|
| **第一方** | 账号名 = 品牌/创始人；简介挂**渠道专属追踪链接**；内容有产品截图/内部视角 | 看简介里的 `域名/r/<渠道>-<随机码>`。**每个渠道一个独立追踪码 = 对每个渠道做效果归因**，不是"发完就完" |
| **付费 KOL（联盟）** | 链接带 `?fpr=<用户名>` 等联盟参数 | 一眼可辨 |
| **付费 KOL（平台备案）** | 平台接口字段（如 B站 `is_union_video = 1`） | 接口字段。⚠️ 只标**平台备案**商单，**私下软广不标** |
| **铺量号 / 矩阵号** | 文本跨账号重复；账号非垂类；时间均匀分散；**账号被平台封禁** | 见第三节的账号级取证 |
| **真实 UGC** | **四项齐验**，不能只看标题 | 见第二节四步法 |

> **联盟分成 vs 逐个谈 KOL**：前者可规模化、可归因、可优化；后者是人力密集型。**如果对手的联盟参数到处都是但商单标记极少，说明它走的是自助式分销。**

## 二、"吐槽"是真用户还是引流号：四步法

**⚠️ 最不可靠的判据是"标题里敢写负面词"。** 实测反例：某 14.6 万粉 UP 主的"是未来黑科技，还是工业垃圾？"**不是对产品的评价，而是他频道的标题模板** —— 他所有视频都是"是 A 还是 B"句式，简介明写接受商业植入。

| 步骤 | 看什么 | 判据 |
|---|---|---|
| **1. 账号的变现钩子** | 简介有没有"商务合作 / 刊例 / 备注品牌+预算"、推广链接、优惠码？→ 有 = **测评号**，不是真用户 |
| **2. 评论区构成** | 真实用户共鸣（具体踩坑、同类经历）vs **网盘/他品引流** |
| **3. 负面是"具体踩坑"还是"情绪词"** | 具体（换了几个模型、烧了多少积分、哪一步失败）→ **真用过**；只有情绪词 → **标题党** |
| **4. 跨作品看作者的标题分布** | 抓主页，不能只看一条。全是同一句式 → **账号选题模板**，与产品无关 |

**辅助信号**：**收藏 > 点赞**（工具类内容典型特征，说明"以后要用"而非情绪认同）。

> **一条平台侧观察**：**负面标题在数据上通常并不占优。** 实测案例里正面实测的最高播放/最高赞都高于负面。"标题党"是信息流里抢点击的手段，不是"内容有价值"的证据。

## 三、操纵识别：三条硬判据

### 3.1 跨账号同类文本 → 操纵成立，但别过度归因

**机制**：付费评论服务的标准动作是**一次性写好几十到几百条文本，发给一批账号，每人自己挑一条复制**。靠**人工标记"谁复制了哪一条"**防撞车 —— 一旦有人忘标记，下一个人就复制到同一条，于是出现**跨账号逐字相同**。

**必须分两层读**：

| 层次 | 结论 |
|---|---|
| **能证明的** | 文本不是真实用户体验 → **操纵事实成立** |
| **不能证明的** | ① 重复**本身**只是流程副产品，不是被指使者要求的；② **下单方是甲方还是第三方服务商，无法区分** |

### 3.2 账号被平台封禁 → 第三方给出的最强证伪

平台比研究者更有能力识别（有注册信息、IP、设备指纹）。**被封号 = 平台给出的结论。**

**Reddit 判定方法**：账号页 HTTP 200，但 `document.title` 退化成通用站名，且正文含 `This account has been banned`。正常账号标题是 `XXX (u/name) - Reddit`。`submitted.json` 返回 403 也是封号信号。

### 3.3 判断"是不是通用服务"：看它跨多少产品出现

**只看单个产品会把"通用服务"误判为"竞品独家手段"。**

实测例子：两个"点评专业户"账号（分别有 30 / 51 条 review）出现在同一天榜单前 8 名里的 **6 个产品页**上，横跨中、美、印、德四个国家的产品。
→ **这是平台上人人可买的第三方服务，不是某个团队的专属手段。** 用它来判断"某国团队是否打榜"是无效的。

> **反过来也说明**：这些文本可能是**批量生成**的 —— 给每个产品一段定制文本，偶尔漏标记就重复。**"逐字相同"是发现操纵的抓手，"文本各不相同"则不代表没有操纵。**

## 四、互动率指标：先拿 cohort 定基线

### 4.1 基线必须是"同类型 + 同量级"

**只锁"同一天同榜单"不够。** 实测：把 cohort 扩到 14 天 / 345 个产品，控制票数区间后：

| 分组 | 中位评论/票数比 | 区间 |
|---|---|---|
| 创业公司（含各国） | **~24%** | 12% – 41% |
| **大厂**（OpenAI / Google / Vercel / Figma…） | **~3%** | 1% – 5% |

→ **真正拉开差距的是"公司类型"，差一个数量级**（大厂票数靠品牌惯性冲高但没人追问细节；创业公司票少但用户会问具体问题）。

### 4.2 选指标前先问：操纵会让它往哪走？

**这是最容易被忽略的一步。**

以"评论 ÷ 票数"为例：

| 情形 | 比值走向 |
|---|---|
| **买票** | **↓ 下降**（分母变大） |
| 买评论 | ↑ 上升 |
| **同时按比例买票 + 买评论** | **≈ 正常，与老实投票无法区分** |

→ **这个比值天生查不出买票。** 所以"比值落在正常区间"**不能推出"票数真实"**。

**通用规则**：**先想清楚"操纵会把指标推向哪个方向"，再决定它能不能当判据。**

### 4.3 检查对照组是否"和被测对象同一来源"

如果拿来当"正常参照"的产品**自己也在用同一套运营手法**，这个基线就是**循环论证**。

**做法**：给每个对照产品做身份核查（创始人发言 / 公司注册信息 / 法律文本管辖地 / LinkedIn），把"不确定"的标出来，**不要强行归类**。

### 4.4 "没有发现操纵证据" ≠ "证明了真实"

当平台不公开投票者明细、投票曲线、账号质量时，**无法独立验证**。
正确表述是：**没发现异常，但也没验证过 —— 存疑。** 不要写成"已证明真实"。

## 五、流量与归因的四个陷阱

### 5.1 帖子浏览量 ≠ 网站访问量

**两者常差 1–2 个数量级。**

KOL 帖的浏览量要乘**站外点击率**（X 通常 **0.5% – 3%**）才是可能的网站访问量。

> 实测：两条 KOL 帖合计 32 万浏览 × 0.5–3% ≈ **3,200–9,700 次访问**，而目标国家的月度流量是 1.3–1.5 万/月 → **KOL 帖最多只能解释约 1/4**。
>
> **这一条能推翻很多"KOL 投放带来 XX 万流量"的说法。**

### 5.2 IP 国别归因受 VPN 污染

SimilarWeb 的国别**按 IP 判定**，所以"某国访客"至少是三种人叠在一起、**且在 IP 层无法区分**：

| 可能身份 | 怎么识别它可能存在 |
|---|---|
| 真实用户 | 有对应语种的内容营销 / 该语言的真实原创内容 |
| **国内用户挂该国梯子** | **该国的常见 VPN 节点同时出现在榜单上、数值接近**；且本土流量占比异常偏低 |
| 该国机房爬虫 | 无法从公开数据区分 |

**看到一个国家占比时，先问三个问题**：
1. 它是不是常见 VPN 节点？
2. 这个国家有没有对应语种的内容营销？
3. 数据是每月快照还是趋势？（**尖峰后回落 = KOL 驱动；长期平稳 = 结构性（真实用户 / 梯子 / 爬虫）**）

**一个反向线索**：如果目标国的头部平台上（如日本之于 YouTube）**零内容**，而该国用户是该平台重度使用者 —— 说明"成型市场"还没形成。

### 5.3 Direct 不是一种渠道，是"归因失败的垃圾桶"

**归因顺序**：先读 referrer → 读不到退到 UTM → 都没有就记成 **Direct**。所以 **Direct ≈ "来源不明"**。

八种成因：直接输网址/书签（唯一名副其实的）、**暗社交**（链接被复制到微信/Discord/Slack/邮件再点开 —— **最大来源**）、**App 内置浏览器**（不传 referrer）、HTTPS→HTTPS 跳转、扫码/App 深链、短链/中转页、从 PDF 点开、隐私模式。

> **看到 Direct 占比高，先问"是不是社群 / IM 驱动"，不要先庆祝品牌力。**
> 两者对增长策略的含义**完全相反**（前者 = 社群承接有效；后者 = 品牌已立住），而第三方工具**永远拆不开** —— 要拆只能自己埋 UTM。

### 5.4 免费版相似工具的字段陷阱

- **只给第 1 名的百分比 + 前 3 名的排名** → **"Direct 排第 2"不等于"Direct 数值很大"**，只能说它 ≥ 第 3 名且 ≤ 第 1 名。
- **"社媒导流结构"的分母是"社媒"，不是全站** → 两张表**不能相加、不能比大小**。
- **额度会打满**，之后所有指标显示 `- -` → **首次抓取就要把结果存全，不要指望复测。**

## 六、需求判断：渠道是"造需求"还是"接需求"

**只看三个问题，能区分出一个渠道的真实角色：**

| # | 判据 | 怎么算 |
|---|---|---|
| 1 | **需求的绝对时序** | 渠道动作发生在需求出现**之前**还是**之后**？ |
| 2 | **搜索词性质** | **品牌词占比高 → 收割已有认知**（navigational）；**品类词占比高 → 捕捉/创造新需求**（commercial） |
| 3 | **快检：同期品类词有没有跟着波动？** | 没波动 → 这个渠道的功劳是"承接"，不是"驱动" |

**判定结果的含义完全不同**：

- **创造了需求** → 该渠道值得加大投入，且要**保护它的"造需求"能力**（热点捕捉、demo 形式）
- **只承接了需求** → 该渠道是**常驻资产**，价值取决于上游有没有事件造出需求；**没有需求时铺量等于对着空场喊话**

> **典型案例形态**：内容池比需求出现早 9 个月，而需求在前 30 个月**始终为零**；内容产量最高的那个月，需求是全期最低；需求的两个峰精确落在两次社媒爆点的**当周**。
> → 结论：**增长（增量）靠事件，留存（存量）靠内容池。**

**顺带必看的一个机会点**：把**品类词**和**品牌词**放同一尺度对照。

- 品类词通常远大于品牌词
- 如果对象**主要吃品牌词、几乎没有品类词布局** → **这是它（和后来者）最大的机会池**
- 具体做法：看它内容产出最猛的那个月，品类需求是否正在峰值 —— **是的话，说明它在错误的方向上用力**

## 七、口径纪律（贯穿全程）

1. **同一个指标在不同口径下能差 50 倍。** 实测：同一产品的抖音声量，"标题口径" = 2 条，"文案+话题全文口径" = 99+ 条。**两个数都对，只是搜索范围不同。**
2. **不写口径的数字没有意义。** 看到第三方数据先问"搜的是什么字段"。
3. **平台站内搜索 ≠ 真实声量**，但**口径不写清楚，交叉验证只会制造假矛盾**。
4. **"查不到"本身是一个信号。** 第三方数据库的收录门槛反映账号权重 —— 别把"没数据"当成"没动作"。

## 八、选渠道 / 选号的判据

**选号，先算「预估阅读 ÷ 预估粉丝」**：

| 比值 | 判断 |
|---|---|
| **> 10%** | 健康，可以投 |
| 5% – 10% | 正常偏弱 |
| **< 5%** | **疑似刷粉，直接排除（不管粉丝多大）** |

实测跨度：一个 246 万粉的号阅读率 **1.5%**，一个 3.7 万粉的号 **22.9%** —— **差 15 倍**。

> **粉丝量可以刷，阅读/粉丝比刷不动。**
> **反过来对自己做号也有用**：这个比值就是你的"真实触达率"，比涨粉数诚实得多。

**判断一个平台是不是"真渠道"**：不要看有没有内容，**要看互动量级**。全是 1–2 票的提及 = 零星提及，不是渠道运营。

## 九、检索手段的自我怀疑

**"检索为空"往往是"检索方法不足"，不是"真的没有"。**

升级检索手段的顺序：

1. 普通网页搜索 → 只看到零星几条
2. 平台**原生 JSON 接口** + 多查询枚举（不同 `sort` × 类型 × 时间窗）→ 数量常常翻十倍
3. **账号级取证**（历史帖、封禁状态、跨产品出现）→ 才能区分真实与投放

**⚠️ 限流会被静默读成"没有数据"。** 接口返回非 200 且 body 为空时，**必须把 status 一并回传**，否则会把 429 限流当成"零结果"。查询之间要留间隔。

**下"No Data"结论之前，先确认自己已经升级过至少两次检索手段。**
